# Brand assets

Both logos have a **transparent background**.

| File | Use |
|---|---|
| `logo-dark.png` | White ink — dark backgrounds. The README serves this one on GitHub's dark theme. 1200×400. |
| `logo-light.png` | Navy ink — light backgrounds. The README serves this one on GitHub's light theme, and as the fallback for renderers without theme switching. 1200×400. |

Both are exported at roughly 2× the README display width and palette-quantized (≈ 60 KB each). The green accents are kept in both.
